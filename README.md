# For Hyunn ♡

Website semangat personal untuk Hyunn dengan desain dark romantic dan responsif.

## File
- `index.html` — struktur halaman
- `style.css` — desain dan layout
- `app.js` — interaksi tombol, pesan acak, checklist, dan pesan rahasia

## Jalankan
Buka `index.html` di browser.

## Deploy ke Netlify
1. Upload folder ini ke repository GitHub.
2. Di Netlify, pilih **Add new site → Import an existing project**.
3. Pilih repository tersebut. Tidak perlu build command.
4. Publish directory isi dengan `.` (root folder).
5. Deploy site, lalu sambungkan domain bila sudah siap.

Website ini statis dan tidak membutuhkan API key atau backend.
